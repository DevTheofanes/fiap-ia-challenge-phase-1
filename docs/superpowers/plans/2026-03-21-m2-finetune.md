# M2 Fine-Tuning Pipeline Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix TRL 0.29 API incompatibilities in `scripts/fine_tune.py` and run training to produce the LoRA adapter checkpoint and ROUGE evaluation log required by M2.

**Architecture:** Single file change — swap `TrainingArguments` for `SFTConfig`, move SFT params into it, and rename `tokenizer→processing_class` in `SFTTrainer`. Everything else (config, data loading, eval script, logging) is already correct and unchanged.

**Tech Stack:** TRL 0.29, transformers 5.3, PEFT 0.18, accelerate 1.13, `meta-llama/Llama-3.2-1B`, MPS (Apple Silicon)
